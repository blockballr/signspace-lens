# Round B6 — Revert hand to wire/bead skeleton

Owner voice. Run this in CLAD, then report back with evidence.

## Context

The MeshBuilder hand currently renders as a solid "capsule tube" style: an opaque
palm ellipsoid with filled finger tubes, `handScale` 1 (canonical ~17 cm). I prefer
the earlier **wire/bead skeleton** that this build started with: 21 joint spheres +
15 thin segment cylinders + a palm volume fit from the landmarks, holographic cream
tint, `handScale` 12 (landmark units × 12), `jointRadius` ~0.045. It reads as a
light, readable signing hand instead of a boxy block. The real cartoon Blender
version is a post-demo project — do not build it now.

## What I want

Restore the wire/bead hand without disturbing the working HUD, SIK, and vocabulary.

1. **`Assets/Scripts/HandRig.ts`** — restore the wire/bead rig construction:
   - Build 21 joint spheres (one per landmark) plus 15 thin segment cylinders
     (one per chain run) plus the palm volume, using two shared unit meshes.
   - Segment cylinders anchored at joint A, scaled to |A-B|, oriented toward B;
     joint spheres cap each segment so no end caps are needed.
   - Palm volume fit from wrist + MCP row landmarks (centroid + MCP span).
   - `HandRigOptions` carries `jointRadius` (fraction of segment radius) again.
   - Keep `getSphereMesh()` — the HUD's body anchor calls it.
2. **`Assets/Scripts/SignSpaceHand.ts`** — drive the wire/bead rig:
   - Pass `jointRadius` (~0.045) to both rigs.
   - Restore the holographic cream tint clone (warm light tone, bright, no darks;
     do NOT force the opaque blend mode used by the capsule version).
   - `handScale` back to 12 (label + hint match: "landmark units multiplied by
     this; ~12 cm gives a natural hand size").
   - Keep the HUD-facing API intact: `getCurrentLabel()`, `getGloss()`,
     `getHandMaterial()`, `getSphereMesh()`, and the `currentGloss` /
     `handMaterial` fields.
3. **`Assets/Scene.scene`** — set the `SignSpaceHand` component's `handScale`
   input to `12`.
4. **Do not touch** the SIK prefab, `SignSpaceHUD.ts`, or the resolver/vocabulary.

## Success criteria (report each)

- Wire/bead rig renders in Desktop Preview: visible joint beads and thin finger
  bones, NOT capsule tubes.
- Scene + script `handScale` = 12, hand is natural signing size in front of the
  camera.
- `HELLO` still signs on start; gloss line reports `HELLO*`.
- HUD readouts still update; SIK prefab still present and quiet.
- Compile gate: zero TypeScript errors.
- No new runtime exceptions in the Logger (list any warnings).

## Report back

- Literal file paths changed and the actual diffs.
- The exact Logger output (sphere/segment mesh stats, gloss line).
- A screenshot or capture path of the Preview showing the wire/bead hand.
- Compile/verify command run and its output.
